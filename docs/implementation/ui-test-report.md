## 二、发现并修复的 Bug

### BUG-1：断点"清除"按钮失效（405 → 500）
- 现象：断点面板点"清除"无反应，浏览器控制台出现 405/500。
- 根因：前端调用 `DELETE /api/breakpoints`，后端该路由只注册了 GET/POST（405）；补上 DELETE 后用了带 `Path<u64>` 的 handler（无路径参数 → 500）。
- 修复：`api.rs` 新增无参 `breakpoint_clear_all` handler 并注册到 `DELETE /api/breakpoints`（执行 clear-all）。
- 验证：`DELETE /api/breakpoints` → `{"cleared":true}` 200；UI 清除正常。

### BUG-2：会话失效/断开后状态轮询持续 409
- 现象：断开/探针丢失/服务重启后，前端仍每 500ms 轮询 `/api/status`，不断返回 409，UI 停在"已连接"。
- 根因：轮询器只在成功时更新状态，收到 `not_connected` 不处理，连接状态不回落。
- 修复：`App.tsx` 轮询器在收到 `error.code == "not_connected"` 时把状态置为 `disconnected`，停止轮询并同步 UI。
- 验证：断开后无 409 风暴，UI 回到"未连接"。

### BUG-3（配置要求）：Flash 需要芯片 target
- 现象：未带 `--target-yaml` 启动时，擦除报 `target has no flash memory definition`，烧录被拒。
- 根因：泛型目标无 Flash 算法；DemoMCU 需要芯片 YAML（`chip generate --flm` 生成）。
- 处理：以 `--target-yaml target/demo.yaml` 启动后 Flash 全流程通过；在 `web` 子命令帮助中补充说明。
- 注意：这是运行配置要求，不是代码缺陷；错误信息已明确。

### 固件能力限制（非缺陷）
- RTT：演示固件未初始化 SEGGER RTT 控制块 → 400（提示明确）。
- EVR：DemoMCU Event Recorder 协议与 probe-rs 不兼容 → 400。

## 四、后续修复（2026-08-30）

### BUG-4：内存面板 u8/u16/u32 宽度"不生效"
- 现象：切换数据宽度后显示几乎不变（顶部字节相同），看起来像宽度没生效。
- 根因：旧实现按宽度改变"读取的元素数量"（u32 读 512 字节、u8 读 128 字节），但**显示始终是逐字节单元格**，没有按宽度分组；且切换宽度时 React 复用输入 DOM 节点（key 不含宽度），导致部分单元格残留旧值。
- 修复（`MemoryPanel.tsx`）：
  - 固定读取 128 字节（u8），宽度只决定显示分组（u16 按 16 位小端、u32 按 32 位小端），切换宽度即时重新分组，无需重读；
  - 单元格 key 加入宽度，避免残留旧值；
  - 组值使用无符号转换（`>>>0`），修复 32 位值最高位置位时显示为负数的问题；
  - 写入按当前宽度整行写（u16/u32 均验证读写一致）。
- 验证：u32 4 单元/行、u16 8 单元/行、u8 16 单元/行；32 位值 `21260018` 等正常显示；u16 写 `ABCD` 读回一致；核心套件 27/27 通过。

## 五、UI 重构（2026-08-30，按用户要求）

### 1. SVD 外设面板：不再新增独立监控变量/监控块
- 新增"全部刷新"按钮：直接读取选中外设的所有可读寄存器，值在位域下方就地显示（实测 GPIOA 11 个寄存器读出 9 个，跳过只写）。
- "监控"按钮改为**就地周期刷新**：点击后该寄存器行显示 `值=0x…●`，按钮变为"停止"；值经 WS 周期更新到同一行内，**不再在下方出现新的"监控中"块**（实测"监控中（周期刷新）"= 0 处）。
- 头部"刷新周期"选择对所有该外设的激活监控生效。

### 2. 默认布局（Keil 风格，LAYOUT_KEY v4）
```
左列：寄存器（上）+ 符号（下）    中心：反汇编（上）+ 控制台（下）    右列：外设（上）+ [内存 | Watch] 页签（下）
```
- 默认窗口即显示 CPU 寄存器，下方符号持久显示；中间上方汇编、下方控制台；右侧上方外设、下方内存；Watch 与内存作为同一页签组点击切换（像 Keil）。
- 其余面板（断点/调用栈/Locals/RTT/EVR/SWO/Profiler/源码）通过"窗口"菜单显隐。
